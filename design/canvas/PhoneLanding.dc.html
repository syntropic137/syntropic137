What is Syntropic137?

Your coding agents, on repeat. Getting better every time.

Syntropic137 turns your coding agents into repeatable workflows. Run them on any harness, see every step, and make every run better than the last. Self-hosted and open source.

1 · Write it once A workflow is a few phases in YAML with prompts in Markdown.
workflows/implement-and-review.yaml 
id: implement-and-review
inputs:
  - name: task
phases:
  - id: implement
    agent: { provider: claude, model: sonnet }
    prompt_template: prompts/implement.md
  - id: review
    agent: { provider: codex, model: gpt-5.6-sol }
    prompt_template: prompts/review.md
2 · Run it anywhere Each phase runs Claude Code or Codex in its own container.
syn workflow run implement-and-review
implementclaude-sonnet-5-5 container ws-1done · 3m 02s
reviewgpt-5.6-sol container ws-2running

04 · Compounding improvement

Every run makes the next one better.

Your run history becomes evals: real bugs replayed against every model and workflow, scored out of 100 by a judge, next to what each run cost. Change a prompt or a model, and see whether it actually helped. Try it: pick a model on the right.
