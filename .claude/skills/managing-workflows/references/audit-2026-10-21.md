# Baseline audit, 2026-10-21

The numbers the skill cites come from this audit. It is a snapshot, not a live
metric: re-run it rather than quoting it after the workflows change.

## Window and source

- **Window:** executions started 2026-10-01 to 2026-10-21 on the owner's
  deployment (the VPS).
- **Source:** read-only `GET` calls to the deployment's API through the
  orchestrator helpers (`syn137-api`, `syn137`): `/executions` (paged) and each
  execution's detail, which carries `status`, `review_verdict`, `phases[]` with
  per-phase cost and duration, and `resumed_from`. PR state came from
  `gh pr list --state all`. The raw pulls were not committed; the queries
  below recompute them.
- **Logical run:** an execution plus the resumes chained from it
  (`resumed_from.parent_execution_id`), counted once.
