List and inspect workflow executions

## `syn execution list`

List all workflow executions

```bash
syn execution list [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--status`, `-s` | `text` | --- | Filter by status |
| `--page` | `text` | `1` | Page number |
| `--page-size` | `text` | `50` | Items per page (max 100) |

---

## `syn execution resume`

Resume a failed execution so it restarts at the first phase that did not finish

```bash
syn execution resume <execution-id> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution to resume |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--override-cancellation` | `boolean` | --- | Resume a CANCELLED execution (a cancel is an instruction to stop) |
| `--acknowledge-external-effects` | `boolean` | --- | Accept that re-running the resumed phase may repeat a push or publish |

---

## `syn execution show`

Show detailed information about a single execution

```bash
syn execution show <execution-id>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID |
