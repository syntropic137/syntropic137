List and inspect workflow executions

## `syn execution list`

List all workflow executions

```bash
syn execution list [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--status`, `-s` | `text` | --- | Filter by status |
| `--page` | `text` | `1` | Page number |
| `--page-size` | `text` | `50` | Items per page (max 100) |

---

## `syn execution sessions`

List every session of a workflow run: platform sessions, invocations and native transcripts, with lineage, gaps and coverage

```bash
syn execution sessions <execution-id> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--refresh` | `boolean` | --- | Schedule durable local reconstruction and report its job |
| `--idempotency-key` | `text` | --- | Reuse a refresh request key when retrying |
| `--json` | `boolean` | --- | Print summary, revision, counts, coverage, gaps, pages and next cursor as JSON |
| `--kind` | `text` | --- | Inventory section: node, membership, edge, capture, gap, binding, retraction (default node; --all reads every section) |
| `--all` | `boolean` | --- | Read every page of every section (or of --kind) from one pinned revision |
| `--phase` | `text` | --- | Only sessions with a membership in this phase ID |
| `--attempt` | `text` | --- | Only sessions with a membership in this attempt ID |
| `--limit` | `text` | `100` | Items per page (1 to 500) |
| `--cursor` | `text` | --- | Continue a previously returned inventory cursor |
| `--require-complete` | `boolean` | --- | Exit nonzero unless coverage is reconciled and the revision is current |

## `syn execution show`

Show detailed information about a single execution

```bash
syn execution show <execution-id>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID |

---

## `syn execution transcript`

Read an exact local transcript archive revision

```bash
syn execution transcript <execution-id> <harness> <native-id> <revision> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID or unique prefix |
| `harness` | `text` | Yes | Native harness namespace |
| `native-id` | `text` | Yes | Full native session ID |
| `revision` | `text` | Yes | Archive SHA-256 from capture evidence |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--raw` | `boolean` | --- | Write verified archive bytes to stdout |
| `--json` | `boolean` | --- | Print metadata and base64 archive bytes as JSON |
