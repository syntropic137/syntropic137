List and inspect workflow executions, their sessions and transcripts

## `syn execution list`

List all workflow executions

```bash
syn execution list [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--status`, `-s` | `text` | --- | Filter by status |
| `--tag` | `text` | --- | Only executions carrying this tag (repeatable; all must match) |
| `--page` | `text` | `1` | Page number |
| `--page-size` | `text` | `50` | Items per page (max 100) |

## `syn execution resume`

Resume a failed execution so it restarts at the first phase that did not finish

```bash
syn execution resume <execution-id> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution to resume |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--override-cancellation` | `boolean` | --- | Resume a CANCELLED execution (a cancel is an instruction to stop) |
| `--acknowledge-external-effects` | `boolean` | --- | Accept that re-running the resumed phase may repeat a push or publish |

## `syn execution sessions`

List every session of a workflow run: platform sessions, invocations and native transcripts, with lineage, gaps and coverage

```bash
syn execution sessions <execution-id> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--refresh` | `boolean` | --- | Schedule durable local reconstruction and report its job |
| `--idempotency-key` | `text` | --- | Reuse a refresh request key when retrying |
| `--json` | `boolean` | --- | Print summary, revision, counts, coverage, gaps, pages and next cursor as JSON |
| `--kind` | `text` | --- | Inventory section: node, membership, edge, capture, gap, binding, retraction (default node; --all reads every section) |
| `--all` | `boolean` | --- | Read every page of every section (or of --kind) from one pinned revision |
| `--phase` | `text` | --- | Only sessions with a membership in this phase ID |
| `--attempt` | `text` | --- | Only sessions with a membership in this attempt ID |
| `--limit` | `text` | `100` | Items per page (1 to 500) |
| `--max-pages` | `text` | `10000` | Stop after this many pages and report the rest as pending (1 to 10000) |
| `--cursor` | `text` | --- | Continue a previously returned inventory cursor |
| `--require-complete` | `boolean` | --- | Exit nonzero unless coverage is reconciled, the revision is current and this call read every section unfiltered (use with --all) |

**Examples:**

```bash
syn execution sessions <execution-id>                  # coverage, counts and the first page of sessions
syn execution sessions <execution-id> --all            # every section: lineage, captures and gaps
syn execution sessions <execution-id> --kind gap --all # only the gaps
syn execution sessions <execution-id> --all --json --require-complete  # automation: nonzero exit unless complete
syn execution sessions <execution-id> --refresh        # schedule a reconstruction and report its job
syn execution transcript <execution-id> <harness> <native-id> <archived-bytes-sha256>  # read one captured transcript
```

## `syn execution show`

Show detailed information about a single execution

```bash
syn execution show <execution-id>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID |

**Examples:**

```bash
syn execution show <execution-id>       # phases, cost and a session inventory summary
syn execution sessions <execution-id> --all   # every session of the run (the summary's Details line)
```

## `syn execution tag`

Add or remove an execution's tags. Idempotent; never replaces the set

```bash
syn execution tag <action> <execution-id> <tags>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `action` | `text` | Yes | add or remove |
| `execution-id` | `text` | Yes | The execution to edit |
| `tags` | `text` | Yes | One or more tags |

**Examples:**

```bash
syn execution tag add <execution-id> eval:baseline     # filter later with --tag eval:baseline
syn execution tag remove <execution-id> nightly        # inherited_tags still records it
```

## `syn execution transcript`

Read an exact local transcript archive revision. Harness, native ID and archived-bytes SHA-256 come from `syn execution sessions <execution-id> --kind capture --all`

```bash
syn execution transcript <execution-id> <harness> <native-id> <revision> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `execution-id` | `text` | Yes | Execution ID or unique prefix |
| `harness` | `text` | Yes | Native harness namespace |
| `native-id` | `text` | Yes | Full native session ID |
| `revision` | `text` | Yes | Archive SHA-256 from capture evidence |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--raw` | `boolean` | --- | Write verified archive bytes to stdout |
| `--json` | `boolean` | --- | Print metadata, normalized conversation and base64 archive bytes as JSON |

**Examples:**

```bash
syn execution sessions <execution-id> --kind capture --all   # find harness, native ID and 'Archived bytes SHA-256'
syn execution transcript <execution-id> claude <native-id> <sha256>          # format, size and revision
syn execution transcript <execution-id> claude <native-id> <sha256> --raw > transcript.raw  # exact archived bytes
```
