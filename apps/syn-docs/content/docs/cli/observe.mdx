Observability: session tool timelines, token metrics, API request latency

## `syn observe latency`

Show API latency to response start (p50/p95/p99) per route

```bash
syn observe latency [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--window`, `-w` | `text` | `24h` | 1h, 24h, 7d or 30d |
| `--route`, `-r` | `text` | --- | One route template as the API reports it, e.g. /evals |

---

## `syn observe tokens`

Show token breakdown for a session

```bash
syn observe tokens <session-id>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `session-id` | `text` | Yes | Session ID |

---

## `syn observe tools`

Show tool execution timeline for a session

```bash
syn observe tools <session-id> [options]
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `session-id` | `text` | Yes | Session ID |

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--limit` | `text` | `100` | Max entries |
