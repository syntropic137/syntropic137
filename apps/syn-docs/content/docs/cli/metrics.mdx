View aggregated workflow and session metrics

## `syn metrics profiles`

Per-phase p50/p90 token and cost, p50/p95 resource profiles for a workflow

```bash
syn metrics profiles [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--workflow`, `-w` | `text` | --- | Workflow ID (required) |
| `--days`, `-d` | `text` | `7` | Look-back window in days |

---

## `syn metrics shipped`

What agents shipped: commits, PRs, merge rate, repos touched vs the previous window

```bash
syn metrics shipped [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--days`, `-d` | `text` | `14` | Window in UTC days: 7, 14 or 30 |
| `--workflow`, `-w` | `text` | --- | Only this workflow's executions |
| `--json` | `boolean` | `false` | Print the API response as JSON |

**Examples:**

```bash
syn metrics shipped --days 14 --json
syn metrics shipped -w sdlc-implement
```

---

## `syn metrics show`

Show aggregated workflow and session metrics

```bash
syn metrics show [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--workflow`, `-w` | `text` | --- | Filter by workflow ID |
