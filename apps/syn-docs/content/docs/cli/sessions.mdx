List and inspect agent sessions

## `syn sessions list`

List platform sessions. For every session of a run (native transcripts, lineage, gaps, coverage) use `syn execution sessions <execution-id>`

```bash
syn sessions list [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--execution` | `text` | --- | Filter platform sessions by execution ID (complete run inventory: `syn execution sessions &lt;execution-id&gt;`) |
| `--workflow`, `-w` | `text` | --- | Filter by workflow ID |
| `--status`, `-s` | `text` | --- | Filter by status |
| `--limit`, `-n` | `text` | `50` | Max results |

**Examples:**

```bash
syn sessions list --execution <execution-id>   # platform sessions only
syn execution sessions <execution-id> --all    # every session: delegates, native transcripts, lineage, gaps
```

---

## `syn sessions show`

Show detailed session information

```bash
syn sessions show <session-id>
```

**Arguments:**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `session-id` | `text` | Yes | Session ID |
