Global system insights and cost analysis

## `syn insights cost`

Show global cost breakdown

```bash
syn insights cost
```

---

## `syn insights heatmap`

Show activity heatmap over time

```bash
syn insights heatmap [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--days`, `-d` | `text` | `14` | Number of days to show |

---

## `syn insights latency`

Show API request latency (p50/p95/p99) per route

```bash
syn insights latency [options]
```

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--window`, `-w` | `text` | `24h` | 1h, 24h, 7d or 30d |
| `--route`, `-r` | `text` | --- | One route template, e.g. /evals/{eval_id} |

---

## `syn insights overview`

Show global overview of systems and health

```bash
syn insights overview
```
