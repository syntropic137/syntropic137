Self-hosted webfonts for syn-ui (declared in src/fonts.css).

Each file is the unmodified latin-subset variable woff2 served by Google Fonts
(fonts.gstatic.com), downloaded 2026-10-09:

  instrument-sans-latin.woff2  Instrument Sans, wght 400-700   OFL-instrumentsans.txt
  jetbrains-mono-latin.woff2   JetBrains Mono,  wght 400-600   OFL-jetbrainsmono.txt
  orbitron-latin.woff2         Orbitron,        wght 500-700   OFL-orbitron.txt

All three are licensed under the SIL Open Font License 1.1. Orbitron declares
the Reserved Font Name "Orbitron": the file is redistributed as served, never
modified, so the name is kept.
